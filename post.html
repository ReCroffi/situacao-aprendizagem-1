Aprendendo HTML

Neste artigo, vou compartilhar minha experiência de aprendizado em HTML durante as aulas de Desenvolvimento Web I na FATEC de Olímpia. Aprender HTML foi uma jornada interessante, cheia de descobertas e desafios. Desde a criação de páginas simples até a implementação de elementos mais complexos, cada etapa contribuiu para o meu crescimento como desenvolvedor web.

Durante as aulas, tive a oportunidade de explorar diferentes tags e atributos, entender a estrutura de um documento HTML e como ele se relaciona com CSS. A prática constante e a resolução de exercícios foram fundamentais para consolidar meu conhecimento.

Entre os principais tópicos estudados, posso destacar:

  • A estrutura básica de um documento HTML, com as declarações de doctype, head e body.
  • Os elementos semânticos do HTML5, como header, main, article, section e footer.
  • A navegação entre páginas, construída com listas e links internos.
  • A inserção de imagens e a importância do texto alternativo para a acessibilidade.
  • Os formulários, com seus campos de entrada, rótulos e validação feita pelo próprio navegador.
  • A estilização com CSS externo, usando flexbox para organizar o leiaute das páginas.
